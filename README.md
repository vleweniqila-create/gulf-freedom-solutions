# Gulf Freedom Solutions

Website for Gulf Freedom Solutions, a veteran-owned web design and social media marketing company serving Panama City, Lynn Haven, Callaway and Panama City Beach, Florida.

The site is a single page (`index.html`) hosted with GitHub Pages.

- Client sites live in `clients/` (for example `clients/hvac-medic/`), each self-contained and deployable on its own.
- Photos: free-to-use images from Unsplash.
- Questionnaire form: sends through Formspree. Replace `YOUR_FORM_ID` in `index.html` with your Formspree form ID.
